# api_retail_enterprise

Proyecto template para un API de retail. Contiene estructura de:

- `app` - paquete principal con routers, modelos, esquemas, servicios y repositorios.
- `.env.example` - variables de entorno de ejemplo.
- `requirements.txt` - dependencias mínimas.

Ubicate en la carpeta raiz y ejecuta lo siguiente:

```bash
uvicorn app.main:app --reload
```
